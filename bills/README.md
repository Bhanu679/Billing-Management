# Bills Directory

This directory stores all generated bills as text files.

Each bill is saved with the following naming convention:
- Filename: `{bill_number}.txt`
- Example: `1234.txt`, `5678.txt`

## Directory Structure
```
bills/
├── 1001.txt
├── 1002.txt
├── 1003.txt
└── ...
```

## Notes
- Bills are automatically created when you save them from the application
- Each bill is a formatted text file containing customer details, items, and totals
- You can open these files with any text editor
- Keep this directory in the same location as the main application file
